## About the Project

**AudioOrderApp** is a Java-based desktop database management application developed as my Bachelor's thesis in Software Engineering at the State University of Trade and Economics.

The project aims to simplify database administration for an audio equipment e-commerce business by providing an intuitive, Ukrainian-language graphical interface that allows users to manage relational data without writing SQL queries manually.

### Key Features

- **Dynamic Database Management:** Connect to Microsoft SQL Server databases and automatically discover available tables and their structures.
- **Full CRUD Functionality:** Create, view, update, and delete database records through dynamically generated forms.
- **Advanced Search:** Filter records using column-specific searches and SQL `LIKE` queries.
- **Schema Inspection:** Explore table structures, column names, and data types.
- **Modern User Interface:** Responsive desktop interface built with JavaFX and MaterialFX.
- **Database Integration:** JDBC-based SQL operations, complemented by JPA entity mappings and Hibernate configuration.
- **Connection Management:** Configurable database connections with persistent non-sensitive connection settings.

### Technology Stack

**Java · JavaFX · MaterialFX · JDBC · Microsoft SQL Server · SQL · Hibernate · JPA · Gradle · JUnit 5**

This project demonstrates practical experience in Java application development, relational database design, SQL integration, object-oriented programming, and desktop UI development.
